# 快速开始与网页控制

适用于固件 0.4.0；速度硬上限 **0.32 m/s**。

1. 架空驱动轮，确认电池极性和电机接线。USB 供电不等于电机已供电。
2. 连接 Wi-Fi `Robot`，密码 `12345678`；有保存配置时以保存值为准。
3. 打开 `http://192.168.4.1`，右上角按键切换中文/英文；页面一次只显示一种语言。
4. 查看 ID1 左轮、ID2 右轮反馈、温度、电流有效性及俯仰/横滚。底盘姿态不包含 Yaw；IMU 调试面板仍保留相对 Yaw。
5. 将驾驶速度调低，设置加速度（m/s²），按住摇杆、W/A/S/D 或方向键驾驶；无需先点使能。松开停止，空格可强制停车。页面已移除 STOP 按钮。
6. 先验证方向、停车和失联保护，再在平地低速测试。

## 加速度、柔性停止与驻坡

驾驶组件的加速度随目标速度发送。打开柔性停止后，松开控制按该加速度减速；关闭时直接停止。故障、心跳超时和 T800 始终直接停用，不等待减速。

自动驻坡打开后仍能正常驾驶，停下来以电流寄存器 60 保持轮位。关闭驻坡，停车后释放扭矩；关闭输出会读回确认，失败自动重试。`release_pending` 时禁止重新运动。电流参数 60 不是 60 A。

定距输入米（负值倒车），定角输入度（正值逆时针），必须从静止启动；结束按驻坡开关决定保持或释放。每段最多 30000 电机步，长动作分段停车，不保证地面绝对位姿。

## 心跳与设置

默认 3 秒没有有效控制更新就停车，设置页可单独保存 100–60000 ms 心跳超时，修改时需停用底盘。网页持续控制时发送更新；页面崩溃或断联后由 ESP32-S3 看门狗停车。定距、减速和驻坡也需要心跳。切换标签、失焦会停止驾驶；不要让多个上位机同时控制。

射灯 0 为关闭，非零从默认 40% 占空比映射到 100%。OLED 使用缓存电池电压，只在停用且通信安静至少 1 秒时后台刷新，首次空闲可刷新，之后间隔至少 60 秒；忙碌时顺延。

步进调试页面属于原始设备调试，输出需主动关闭，不等同于底盘看门狗保护。标准底盘无需 TTL Node，OLED/IMU 缺失不阻止双轮运动。
